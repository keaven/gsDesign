# Presentations

These slide decks are supporting materials hosted in the GitHub repository.
The `presentations/` directory is excluded from the R source package through
`.Rbuildignore`, so these files are not included in CRAN submissions.

- `gsSurvPower-scenario-analysis-v3.11.0.pptx` is the current presentation on
  `gsSurvPower()` scenario analysis for gsDesign 3.11.0.
- `gsSurvPower-presentation.pptx` is the earlier working version retained for
  reference.
